## ▶ How to Run
1. Upload `pico_firmware/` files to Raspberry Pi Pico
2. Connect Pico to PC using USB
3. Run Java dashboard
4. Select COM port and click **Connect**
5. Control robot and monitor sensors

---

## 🎓 Internship & Viva Notes
- Java runs on PC, not on Pico
- Pico handles hardware control
- USB Serial is primary communication
- Clean modular design
- Real-time monitoring dashboard
